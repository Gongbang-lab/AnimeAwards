# 수집기 작업 연도

모든 HTML 수집기와 `animeDataOverview.html` 왼쪽 사이드바에서 작업 연도를 입력하고 **연도 적용**을 누릅니다. 마지막으로 선택한 연도는 다른 수집기에서도 사용됩니다. 주소 뒤에 `?year=2027`을 붙여 직접 열 수도 있습니다.

## 데이터 준비 순서

1. 애니메이션 수집기에서 작업 연도를 선택합니다.
2. 생성한 데이터를 복사하여 `data/2027/2027animeData.js`처럼 해당 연도 폴더에 저장합니다. 변수명도 `AnimeCatalog_2027`처럼 자동 생성됩니다.
3. 각색·감독·각본·스튜디오 수집기는 해당 연도의 애니메이션 데이터를 읽습니다. 성우 수집기는 해당 연도의 캐릭터 데이터가 먼저 필요합니다.
4. 곡·에피소드·밈·OST 수집기는 선택 연도에 저장된 데이터를 불러옵니다. 파일을 읽지 못하면 편집과 내보내기를 중단합니다. 공개 전인 새 연도에 아직 만들지 않은 파일은 사이드바의 **새로 작성** 버튼으로 빈 목록에서 시작할 수 있습니다.
5. 결과 파일을 저장한 뒤 데이터 현황 페이지에서 같은 연도를 선택하면 OP·ED·OST·에피소드·PV 등록 현황을 볼 수 있습니다. 이미 열려 있던 페이지는 새로고침합니다.

파일명과 변수명의 연도가 모두 작업 연도와 같아야 합니다. 파일을 읽을 수 없거나 변수명·자료형·문법이 올바르지 않으면 사이드바에 오류를 표시하고 편집·복사·다운로드를 잠급니다. 다른 연도 데이터나 빈 데이터로 자동 대체하지 않습니다. **다시 불러오기**로 재시도할 수 있습니다.

OST 수집기는 앨범의 iTunes ID를 `collection_id`에 함께 저장합니다. 이전 파일은 트랙의 `itunes_url`에서 ID를 복원하며, 같은 앨범을 다시 추가하면 기존 트랙을 유지하고 누락된 트랙을 합칩니다.

## 저장과 연도 전환

- 기존 복사·다운로드 방식은 유지됩니다. 원본 JS 파일을 자동으로 덮어쓰지 않습니다.
- 에피소드와 캐릭터처럼 작품 단위 결과를 제공하던 도구는 그 출력 형식을 유지합니다. 해당 연도의 전체 데이터 파일에 반영하세요.
- 연도를 전환하면 페이지가 다시 열립니다. 복사하지 않은 편집 내용과 진행 중인 API 수집은 보존되지 않으므로 먼저 저장하세요.
- 애니메이션 편집 임시 저장, 루키 캐시, OST 수집함은 연도별로 구분됩니다. OST는 같은 연도의 임시 수집함이 있으면 파일 데이터보다 우선 복원합니다.
- 수집기의 연도 선택은 시상식 공개 목록과 별개입니다. 2027년 자료를 준비해도 인덱스에 2027년 버튼이 자동으로 추가되지 않습니다. 공개 시점에 `data/manifest.js`의 연도 목록을 갱신합니다.
